Overview

问题：从黑盒的 \(Z(f)\) 恢复电路 \((G,\theta)\)

测量能给我们什么

  • 对数扫频得到离散复阻抗序列 \(\{(f_k,\,Z_k)\}_{k=1..M}\)，本例 \(M=20\ldots40\)，10 Hz–10 kHz。
  • 唯一可观测的是端口行为 \(Z(s)\)；内部结构需要靠"假设—计算—比较"的逆问题求解。

三个引擎 = 同一逆问题的三档先验

引擎已知未知核心动作

Unified Forward Model

核心抽象：电路 = 多重图

图论语言

  • 顶点 = 电气连接点；边 = 一个元件；端口固定为节点 0 / 1。
  • 允许重边（同节点对多个元件 = 并联），不允许自环；无互感、无受控源。
  • 电感绑定直流电阻：\(L{+}R_d\) 是一个器件、最多两个参数；\(R_d\ge 0\) 可精确为零。
取 \(s=j2\pi f\)，元件阻抗与导纳： \[ z_R=R,\qquad z_C=\frac{1}{sC},\qquad z_L=R_d+sL, \qquad y_e=\frac{1}{z_e} \]
有了这一层抽象，"搜索电路结构"就变成搜索图：Try1/Try2 的离散部分都在图的组合空间上进行。
示例：3 节点、3 条边 \(L\parallel(R+C)\) 的图与它的节点导纳矩阵

Unified Forward Model

前向模型 I：每条边向 \(Y\) "盖一次章"

边的 stamp（导纳 \(y\)，端点 \(u,v\)）

\[ Y_{uu}\mathrel{+}=y,\qquad Y_{vv}\mathrel{+}=y,\qquad Y_{uv}\mathrel{-}=y,\qquad Y_{vu}\mathrel{-}=y \]
  • 地（端口 0）电压恒为 0：不进入未知量，只盖非地端的对角元。
  • 写成矩阵语言：\(Y(s)=\sum_e y_e(s)\,a_e a_e^{\mathsf T}\)，其中 \(a_e\) 在 \(u\) 处 \(+1\)、\(v\) 处 \(-1\)——每加一个元件 = 给 \(Y\) 加一个秩 1 矩阵。

最小例子：节点 1、2 之间一条电阻 \(R\)，\(g=1/R\)

\[ Y=\begin{bmatrix} g & -g\\ -g & g\end{bmatrix} \qquad\text{——再复杂的图也只是"多盖几次章"} \]

为什么用节点导纳矩阵

  • KCL 的直接离散形式，组装是局部、可加的。
  • 串并联公式只是它在特殊拓扑下的化简结果；节点法天然处理桥式、重边、任意小型图——这正是 Try2 能搜索桥式网络的原因。

Unified Forward Model

前向模型 II：端口阻抗 \(Z=b^{\mathsf T}Y^{-1}b\)

四步推导（单位电流激励）

  • 端口 0 接地；向端口 1 强制注入 \(1\,\mathrm{A}\)：右端 \(b=e_1\)（端口 1 对应的单位向量）。
  • KCL 矩阵形式：\(Yv=b\)，解得 \(v=Y^{-1}b\)。
  • 因为 \(I_{\text{port}}=1\,\mathrm{A}\)，端口阻抗就是端口电压：\(Z=V_1\)。
\[ Z \;=\; V_1 \;=\; b^{\mathsf T}v \;=\; b^{\mathsf T}Y^{-1}b \]

手算验证：\(R\)–\(C\) 串联（故意不用串联公式）

未知节点 \(\{1,2\}\)，\(g=1/R,\;y_C=j\omega C\)： \[ Y=\begin{bmatrix} g & -g\\ -g & g+y_C\end{bmatrix},\quad b=\begin{bmatrix}1\\0\end{bmatrix} \;\Rightarrow\; Z=\frac{g+y_C}{g\,y_C}=R+\frac{1}{j\omega C}\;\checkmark \]

数值可靠性（nodal.cpp）

  • 矩阵按最大模缩放后 FullPivLU 求解。
  • 报告有效 rcond（含装配级 LC 导纳相消，一维矩阵的普通条件数恒为 1、查不出这类风险）与后向误差 \(\|Yv-b\|/(\|Y\|\|v\|+\|b\|)\)。
  • 状态机：OK / PORT_OPEN / SINGULAR / ILL_CONDITIONED / NONFINITE——不用巨大哨兵值掩盖失败。

Fitting Objective

拟合与测量的差距怎么量化：残差、wRMSE 与 AICc

白化相对残差（默认噪声模型）

\[ z_{\text{floor}}=\max\!\bigl(10^{-15},\;10^{-9}\,\mathrm{median}|Z_k|\bigr),\qquad r_k=\frac{\begin{bmatrix}\mathrm{Re}(\hat Z_k-Z_k)\\[2pt] \mathrm{Im}(\hat Z_k-Z_k)\end{bmatrix}}{\max(|Z_k|,\,z_{\text{floor}})} \]
  • 目标函数 \(J=\sum_k\|r_k\|^2\)（相对加权：\(1\,\mathrm{k\Omega}\) 与 \(1\,\mathrm{\Omega}\) 的数据同等对待；近零保护防除零）。
  • 报告指标：wRMSE \(=\sqrt{\overline{\|r_k\|^2}}\)（整体相对误差）与 maxRel（最差点）；可选逐点协方差做 GLS。

复杂度惩罚：AICc（小样本修正 AIC）

\[ \mathrm{AICc}=n\log\!\bigl(\max(J/n,10^{-300})\bigr)+2k+\frac{2k(k+1)}{n-k-1}, \qquad n=2M,\;k=p+1 \]
观测数 \(n\) 是 \(2M\) 个实分量；\(p\) 为自由电参数数，\(+1\) 是未知的共同方差。参数越多惩罚越重，防止"多加元件总能更低残差"的过拟合。

鲁棒选项（只影响拟合权重）

  • Huber IRLS：对白化残差范数取 \(2.5\times\)中位数为阈值降权，至多 3 轮，要求过半点保持内点。
  • 原始相对权重的 wRMSE / maxRel 始终照常报告，异常点不从报告中消失。
  • robust 运行不参与 AICc 校准选择，按 RSS 诊断回退排序。
这些指标对所有引擎统一：Try1 用它做模型选择，Try2 用它给接线排序，Try3 用它报告单拓扑拟合质量。

Try3 · 已知拓扑，反求数值

最优元件数值怎么算（I）：参数化、初值与多起点

优化坐标：让数量级成为"平移"

  • 正参数 R/L/C 用对数坐标 \(x=\log_{10}q\)，链式因子 \(\ln 10\cdot q\)；跨 10 个数量级的搜索变成均匀空间。
  • DCR 用缩放线性非负坐标 \(x=R_d/z_{\text{scale}}\)，\(z_{\text{scale}}=\max(10^{-9},\mathrm{median}|Z|)\)——可以精确到达 0（softplus 做不到，故不采用）。
  • 箱约束显式投影：默认 \(R\in[10^{-3},10^{7}]\,\Omega\)、\(L\in[10^{-10},10]\,\mathrm{H}\)、\(C\in[10^{-13},10^{-3}]\,\mathrm{F}\)、\(R_d\in[0,10^{7}]\,\Omega\)。

物理尺度初值（不靠运气起步）

\[ \omega_c=2\pi\sqrt{f_{\min}f_{\max}},\qquad R_0=z_{\text{scale}},\quad L_0=\frac{z_{\text{scale}}}{\omega_c},\quad C_0=\frac{1}{z_{\text{scale}}\,\omega_c},\quad R_{d,0}=0.1\,z_{\text{scale}} \]
"中位阻抗 × 频带几何中心"给出各类型元件的正确量级——如 \(|Z|\sim1\,\mathrm{k\Omega}\)、\(f_c\sim1\,\mathrm{kHz}\) 时 \(C_0\sim0.16\,\mu\mathrm{F}\)。

确定性多起点

  • 默认 16 个起点 × 160 轮，随机种子固定 1——结果完全可复现。
  • 起点 0 = 物理尺度初值；其余在对数坐标上加 \(\pm2.5\) 个数量级的均匀抖动（容差模式则在箱内均匀采样）。
  • DCR 每 4 个起点强制一次 0 初值（零 DCR 是常见真相）。
  • 取全部起点的最优；"多少起点收敛到同一解"（agreeingStarts）本身是诊断量。

最优元件数值怎么算（II）：解析灵敏度 + Levenberg–Marquardt

解析 Jacobian：对 \(Yv=b\) 微分（普通转置，非共轭）

\[ \frac{\partial Z}{\partial q_e}=-\frac{\partial y_e}{\partial q_e}\,\bigl(V_u-V_v\bigr)^{2}, \qquad \partial_R y=-\tfrac{1}{R^2},\;\; \partial_C y=s,\;\; \partial_L y=\tfrac{-s}{(R_d+sL)^2},\;\; \partial_{R_d} y=\tfrac{-1}{(R_d+sL)^2} \]
  • 直觉：元件两端电压差 \(\approx 0\;\Rightarrow\;\partial Z/\partial q\approx 0\)——端口"看不见"它，也就无法从端口数据确定它（可辨识性的根源）。

阻尼最小二乘步（增广方程，SVD 直接求解）

\[ \min_{\Delta}\left\| \begin{bmatrix} J\\ \sqrt{\lambda}\,D\end{bmatrix}\Delta+ \begin{bmatrix} r\\ 0\end{bmatrix} \right\|_2, \qquad D_{jj}=\max\!\bigl(10^{-8},\|J_{:j}\|\bigr) \]
  • JacobiSVD 解增广最小二乘，不形成法方程 \(J^{\mathsf T}J\)（避免平方条件数）。
  • 信赖域：单坐标最大步长 2（对数坐标下约 100 倍），越界投影回箱。
  • \(\lambda\) 自适应：初始 \(10^{-3}\)，成功 \(/3\)、失败 \(\times 10\)；\(\lambda>10^{14}\) 判停滞。
  • 终止：缩放梯度 \(<10^{-10}\) / 代价 \(<10^{-24}\) / 增益微小 / 迭代上限——状态显式输出。

  • 死区：仅经一个割点挂接且不含另一端口的子网络，对 \(Z\) 无贡献（如悬挂三角形）。
  • 恒等归约：并联 R 倒数和 / 并联 C 求和；串联同类相加；串联 R 折入 L 的 DCR；不合并并联 L+DCR。
  • 归约群允许域按表达式单调传播（两个 rMax 串联可达 \(2\,r_{\max}\)，不被单器件箱误删）。

拟合后：可辨识性诊断（而不是"猜完了就完了"）

  • 加权实 Jacobian 的 SVD：数值秩、奇异值、条件数——满列秩支持局部可辨识；单点秩亏不自动证明全局参数族。
  • 弹性度 \(\max_f |q\,\partial Z/\partial q|/|Z|<0.1\) 标记 weak；atBound、多起点一致性（agreeingStarts）单独报告。
  • 条件满足时给线性化 SE 与 95% 区间：\(C_x=V\,\mathrm{diag}(\sigma_i^{-2})V^{\mathsf T}\cdot\frac{J}{n-p}\)，对数坐标经 \(10^{x}\) 映射回物理单位。
  • 结论分级：IDENTIFIABLE_LOCAL / AMBIGUOUS_EQUIVALENCE_CLASS / NUMERICALLY_UNSTABLE / DATA_INSUFFICIENT / LOCAL_FIT_UNCONFIRMED。
真实案例 data4：rank 5/5、条件数 32.8、9/16 起点一致——局部可辨识；但 \(R_1\) 回收 138 Ω，CI [132.6, 144.1] 不含标称 200 Ω：并联槽路阻尼由 \(R_1\) 与 L 的 DCR 强相关地共同提供。

Try2 · 已知器件，搜索接线

图怎么搜（I）：有限空间的完整枚举

节点数范围

\[ \text{连通且含两端口}\;\Longleftrightarrow\; 2\le V\le E+1 \qquad\bigl(E\ge V-1\bigr) \]
  • \(V\) 个节点的连通图至少 \(V-1\) 条边；两个端口本身就要 2 个节点。
  • 固定 \(V\) 后：\(\binom{V}{2}\) 个节点对槽位，\(E\) 条边 = 槽位上大小为 \(E\) 的多重集，例如 \(V{=}3\)：\(m_{01}+m_{02}+m_{12}=E\)。
  • DFS 取槽位时允许重复取同一槽 → 天然支持并联重边；不允许自环。

剪掉重复与无效：规范化（canonicalization）

  • 结构过滤：无孤立节点；活动性检查（所有元件必须端口连通，完整割点死区直接排除）。
  • 内部节点重命名与互易端口交换不改变电路 → 枚举全部置换，取字典序最小签名作为"身份证"去重（同一电路只算一次）。
  • 器件赋值：把已知的 \(E\) 个器件排到边上，跳过相同器件的重复排列，带值图再做一次规范化去重。
  • 支持 \(E\le 8\)，包含桥式与重边；组合数随 \(E\) 急增（\(E{=}7\) 已到百万级）。

Try1 · 一无所知，盲搜模型

Try1（I）：规范串并联（SP）树的枚举

假设空间：SP 表达式树

  • 叶子 = 器件 R / C / L(+DCR)；内部节点只有 SER（串联）与 PAR（并联）两种运算。
  • 逐层递归构造：\(n\) 个器件的树由"器件数拆分 + 交替运算"组合而成，子树类型必须与父节点不同（S 下不再套 S），深度 ≤ maxDepth。
\[ Z_S=\sum_i Z_i,\qquad Z_P=\Bigl(\sum_i \frac{1}{Z_i}\Bigr)^{-1} \quad\text{——树自叶向根即可算 } Z \]

规范化规则：同一电路只留一棵树

  • 同运算扁平化：\(S(S(a,b),c)\to S(a,b,c)\)；子树按规范键排序。
  • 不生成可直接归约的结构：SER 下同类叶、SER 下 \(R{+}L\)（折入 DCR）；PAR 下同类 R/C 不生成，但保留并联 L（不同 DCR 时间常数不可合并）。
  • 默认 maxN=4、maxDepth=4：130 棵规范树（n=1..4，真实运行计数）；exactN 可锁定器件数层。
  • "器件数"是规范不可约等效模型的器件数，不是 PCB 物理封装数。
每棵树 expand 成图（SER 链生成内部节点）后，进入同一个 \(Z=b^{\mathsf T}Y^{-1}b\) 前向求值与共享拟合——Try1 的"猜测"与 Try2/Try3 的"计算"无缝衔接。

Try1 · 一无所知，盲搜模型

Try1（II）：有理拟合 → Foster 辅助候选

辅助路径：从数据直接综合出候选电路

  • 尺度化（\(s/\omega_0\)、\(Z/Z_0\)，\(\omega_0\) 取频带几何中心）后做实系数有理最小二乘。
  • 解分母校正后用特征值重定位移动极点，再重拟合留数（vector fitting 思想的实数基版本）。
  • 稳定极点 ≠ 无源性：只接纳能显式综合为正值器件的 Foster 类实现。

两个被接纳的综合单元（归一化坐标，含尺度恢复）

\[ \frac{K}{s+a}=R\parallel C:\;\; R=\frac{K}{a},\;C=\frac{1}{K} \qquad\qquad \frac{Ks}{s^2+as+b}=R\parallel L\parallel C:\;\; R=\frac{K}{a},\;L=\frac{K}{b},\;C=\frac{1}{K} \]
  • 综合出的候选必须通过共享前向模型的一致性核对，再进入公共参数精调与统一排序。
  • 综合失败只是丢弃该辅助候选，绝不删除 SP 假设（不因辅助路径失败而漏掉合法模型）。
  • 输出族 family=NORMALIZED_SP_PLUS_FOSTER；辅助候选同样受器件数约束。

定位与边界

  • 这是一个明确的 Foster 子族，不是任意正实函数的通用综合（不含 Cauer/Brune）。
  • SP 离散枚举完整 ≠ 连续内层全局最优；也不宣称真实桥式结构一定在假设空间内。
  • Strict 模式不做未证明安全的"有限频带斜率删枝"。

Honest Boundaries

哪些结论不能宣称（以及为什么）

  • 端口行为 ≠ 物理内部。单端口测量首先辨识 \(Z(s)\)，再找它的一个实现：\(R_1{+}R_2\) 与等值 R、\(R{+}(R_d{+}sL)\) 与等值 L+DCR 永远不可区分；exactN 是等效模型器件数，不是 BOM 数。
  • 行为等价是数值的、局部的。observed-grid 等价只在观测频点上成立；不同拓扑可以有几乎相同的驱动点阻抗。实测例：Try1 在 data4 的 rank-1 为 \(R{+}\bigl(L\parallel(C{+}R')\bigr)\)，与真值 \(R_2{+}(R_1\parallel L\parallel C)\) 结构不同、wRMSE 同为 0.50%。
  • 局部最优无全局证书。多起点只能提高可信度（agreeingStarts 是诊断），不能证明连续参数全局最优；Try2.5/Tolerance/连续拟合一律 continuous_global_certified=false。
  • 满秩 ≠ 唯一。正则内点满列秩只支持局部可辨识；单点秩亏也不自动证明存在全局连续参数族。weak 弹性度是经验阈值。
  • 数值诊断不是误差界。rcond/后向误差是浮点可靠性诊断；AICc 在非线性、有界、系统误差场景只是近似诊断，不是校准的模型概率。

成果如何如实呈现

  • Top-K 输出行为等价类代表元与成员数，而非"唯一电路"。
  • 每个候选携带自己的诊断（收敛、秩、边界、数值状态）。
  • 枚举完成 / 预算耗尽 / 数值警告在运行级分开标记。
  • 失败与部分结果显式暴露，不用哨兵值掩盖。
这套"诚实边界"本身就是设计目标的一部分：让使用者知道每个数字的可信度层级。

Summary

总结：一条管线，三档先验

统一管线（三个引擎共享同一个数学实现）

测量 \(Z(f_k)\)
→
候选 \((G,\theta)\)
→
stamp 组装 \(Y(s)\)
→
\(Z_{\text{calc}}=b^{\mathsf T}Y^{-1}b\)
→
白化残差 \(r_k\)
→
\(J=\sum\|r_k\|^2\)
→
搜索 / LM 优化
→
分层排序 Top-K + 诊断

三个关键公式

\[ Z=b^{\mathsf T}Y^{-1}b,\qquad \frac{\partial Z}{\partial q_e}=-\frac{\partial y_e}{\partial q_e}(V_u-V_v)^2 \] \[ \mathrm{AICc}=n\log(J/n)+2k+\frac{2k(k+1)}{n-k-1} \]

三个引擎一句话

  • Try1：枚举规范 SP 树 + Foster 辅助——结构、类型、数值全要猜。
  • Try2：器件已知，完整枚举非同构多重图——结构猜完直接比。
  • Try3：结构已知，归约 + 解析灵敏度 LM——把数值钉到最优点并给出可辨识性诊断。
每猜出一个候选电路，判断方法永远一样：灌 1 A 电流 → 解 \(Yv=b\) → \(Z=V_1\) → 与测量比较。
